# Балхаш 2026

Один статический сайт с тремя разделами (переключение вкладками, без бэкенда и сборки):

- **Маршрут** — дорожный лист Екатеринбург → Балхаш (км, платные участки, топливо, документы, особенности Казахстана)
- **Снаряжение** — чек-лист для стоянки на озере и ночёвки в машине
- **Книги** — подборка для чтения на озере с фильтрами по теме

Всё в одном файле `index.html` — без внешних шрифтов/CSS/JS фреймворков, чтобы быстро грузилось даже на плохом интернете. Обложки книг подгружаются с Open Library только при открытии вкладки «Книги» и не блокируют остальное.

## Публикация

GitHub Pages: Settings → Pages → Deploy from branch → `main` / `/ (root)`.
